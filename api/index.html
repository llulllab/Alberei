Alberei API · v1

Robots and apps don't need to be funny. We are.

Alberei is a modular humour engine. Plug it in and your product gets register-aware, culturally specific humour generation across 12 languages. Built for embodied agents, voice assistants, chatbots, game NPCs, and content tools.

Quickstart

One endpoint. JSON in, items out. Replace YOUR_TOKEN with a token issued through the access flow below.

curl -X POST https://api.llulllab.com/alberei/v1/generate \
  -H "Content-Type: application/json" \
  -H "X-Api-Token: YOUR_TOKEN" \
  -d '{
    "lang": "en",
    "context": "user just asked the robot why it'"'"'s slow today",
    "count": 3,
    "register": "wry"
  }'

Returns three short humour items in English, in the wry register, each tagged with its combinatorial structure.

Endpoint

POST /alberei/v1/generate

Generate humour items for a single context. One call, one to five items.

Rate-limit headers

All responses carry: X-RateLimit-Tier, X-RateLimit-Daily-Remaining, X-RateLimit-Monthly-Remaining, X-RateLimit-Burst-Remaining. The Retry-After header is returned with 402 and 429.

Usage endpoint

GET /alberei/v1/usage

Return the current quota state for the token. Useful for dashboards, threshold alerts, and pre-flight checks before a batch. POST with the same header is also accepted for clients that prefer a uniform method.

curl https://api.llulllab.com/alberei/v1/usage \
  -H "X-Api-Token: YOUR_TOKEN"

Response (200 OK)

{
  "tier": "starter",
  "monthly_quota": 5000,
  "monthly_used": 127,
  "monthly_remaining": 4873,
  "daily_remaining": 142,
  "burst_remaining_per_minute": 58,

  "period_end":   "2026-05-31T23:59:59.000Z"

The period_start and period_end bound the current monthly window in UTC. Quotas reset on the first of each calendar month.

Registers

Four named registers. The set is locked for v1; pick the one that fits your product's voice.

wryDry, ironic, self-aware. Default.
absurdSurreal, logic-breaking, unexpected.
deadpanFlat, affect-less, unreactive delivery.
warmAffectionate, inclusive, kind humour.

Languages

All 12 languages available at launch. Each generates natively, with culturally specific framing, not translated from a base language.

Where Alberei fits

  • Embodied agents. Give your social robot or home assistant a humour module that fires when conversational context calls for it.
  • Voice assistants. Smart speakers and call-handling agents respond with culturally specific wit instead of canned lines.
  • Chatbots. Customer-service and companion bots gain a personality layer that adapts to the user's language and tone.
  • Game NPC dialogue. Inject combinatorial humour into procedural dialogue without writing every line by hand.
  • Content tools. Writing assistants, video editors, and podcast scripts get a humour suggestion endpoint.
Inaugural pilot. Phi-Yo Embodied, Llull Lab's wellbeing companion robot, uses Alberei as its humour module. The integration ships with the first production hardware run.
